## 本次采用的表述边界

- 30次实验在各自工况内训练和测试，不是新增的跨工况直接迁移实验。
- 三个seed共享数据，30次运行并非30个独立设备；PPT只展示均值和标准差，不把旧的逐运行t区间作为严格置信区间。
- Trend由Level计算，方向一致率具有内部依赖关系；Movement不必与径向Level变化强相关。
- Bearing1_4的MSE比较组含训练与验证bearing，因此1.77倍不能单独证明Encoder失效或分布偏移。
- 改变校准长度也改变评价时间范围，不能直接将更高ρ解释为参数改善。
