# Arm A/B 联合评估非盲演练

## 目的

在正式读取 `Bearing2_5` 前，用已经参与开发的 `Bearing2_4` 验证联合评估程序是否能在一次执行中公平地运行两个冻结分支。本演练只验证流程，不产生新的科学结论。

## 联合流程

```text
Bearing2_4 原始测量
→ 只读取并进行一次 STFT 物化
→ Arm A：源工况归一化 + 源 AutoEncoder + 固定 Interpreter
→ Arm B：目标工况归一化 + 目标 AutoEncoder + 固定 Interpreter
→ 同时报告两组状态、ρ 和 Δρ
```

两个分支均使用15步校准、10点窗口以及 `[level, trend, movement]`。脚本的 `rehearsal` 模式只能选择 `Bearing2_4`；`blind` 模式需要精确的一次性确认令牌，否则在数据读取前退出。

## 演练结果

- 原始测量：42个，只物化一次。
- 联合状态：84行，即两个分支各42行。
- Arm A：ρ=0.6813186813。
- Arm B：ρ=0.9932844933。
- Δρ=+0.3119658120。
- 两个结果与此前独立开发运行逐项完全一致，ρ差值均为0。
- 输出 bearing 与 source path 中 `Bearing2_5` 均为0行。
- 配置、Arm A checkpoint、Arm B checkpoint 哈希均验证一致。
- 全量测试：66 passed。

## 遇到的问题

第一次演练在读取数据前，因为直接比较包含 Tensor 的预处理器字典而退出。修复为逐项比较 `n_fft`、`win_length`、`hop_length` 和 `output_size` 后，经用户明确确认才重新运行；失败运行没有创建结果目录，也没有读取任何 bearing。

## 结论与边界

联合评估管线已经具备正式盲测所需的主要工程能力：共享一次输入物化、分别使用正确归一化与 checkpoint、冻结解释器参数、同步生成比较结果，并阻止无确认的盲测执行。

本周工作在此结束。`Bearing2_5` 仍未读取。正式盲测前还应记录最终脚本哈希并再次确认执行，运行后禁止根据结果调参。
