# v2.1 只读配置与数据泄漏保护层

## 任务边界

本步骤只实现公共配置读取和安全校验，不修改 v1 训练脚本、不运行 AutoEncoder 训练、不提取新工况 latent，也不读取 `Bearing2_5`。

## 实现内容

新增 `state_interpreter.experiment_config`：

- 将 v2.1 JSON 解析为冻结 dataclass，运行代码不能直接修改配置对象；
- 检查训练、验证和严格盲测 bearing 互斥；
- 检查分支B训练与归一化 bearing 完全等于预注册训练划分；
- 禁止开发阶段选择 `Bearing2_5`；
- 检查分支A禁止训练，并必须加载源 checkpoint 的归一化参数；
- 检查联合盲测尚未执行、必须由一个脚本读取一次并同时报告两分支；
- 校验源 checkpoint 和 v1 配置的 SHA-256；
- 限制冻结工件路径必须位于仓库内部。

配置只负责声明实验，不在执行后被改写。阶段完成状态单独写入 `records/xjtu_cross_condition_v2_1/`。

## 验证结果

- 完整测试：55项全部通过；
- 新增安全测试：7项；
- 真实 v2.1 配置可以成功加载；
- 分支A开发数据只返回 `Bearing2_1–2_4`；
- 分支B训练数据只返回 `Bearing2_1–2_3`；
- `Bearing2_5` 只作为受保护名称返回，没有读取原始数据；
- v1 checkpoint 与 v1 配置哈希均与预注册值一致。

第一次测试中有41项通过、14项因 pytest 临时目录权限无法创建而报错。改用系统临时目录后，55项全部通过；这属于测试环境问题，不是代码逻辑失败。
