# Condition 3 Feature LSTM失败定位（2026-09-18）

## Material Passport

- Diagnosis ID: `xjtu_condition3_feature_failure_diagnosis_v1`
- Verification status: `ANALYZED`
- Scope: B3_1–B3_3既有特征缓存
- Protected: B3_4/B3_5未读取
- Feature LSTM training: 未再次训练或调参

## 研究问题

开发门槛失败究竟主要来自模型容量不足，还是输入表示本身缺乏跨bearing一致性？诊断在运行前固定四类证据：bearing身份探针、feature–lifetime方向、Ridge LOBO映射以及时间窗口尺度。

## 核心证据

### 1. 表示中存在强bearing身份

使用每个bearing等量300点，并按五个连续生命周期区间做held-block nearest-centroid探针。总体bearing身份准确率为`90.3%`，远高于三分类随机水平`33.3%`；五个区间准确率为83.3%、90.0%、100%、100%和78.5%。

这说明即使经过每bearing早期校准和signed-log压缩，65维表示仍强烈保留设备身份。

### 2. 健康方向在bearing之间冲突

65个特征中：

- 34个特征出现稳健方向冲突，即至少两个bearing的`|ρ|≥0.3`且符号相反；
- 只有1个特征在三个bearing上同时达到`|ρ|≥0.3`并保持同向。

典型例子是水平RMS：B3_1/B3_2为正相关约0.414/0.865，而B3_3为负相关−0.511。模型无法用一套共享权重把这种相反运动稳定映射为同一个健康方向。

### 3. 共享RUL映射不存在

使用两个bearing训练固定alpha=1的Ridge，再在第三个bearing测试，LOBO Spearman分别为：

- B3_1：−0.111；
- B3_2：−0.474；
- B3_3：−0.199。

因此问题并非仅是LSTM优化困难；简单共享映射同样全面反向。

### 4. 10步窗口代表的相对时间不一致

10步分别只占B3_1生命周期的0.394%、B3_2的0.401%，但占B3_3的2.703%。B3_1/B3_2在lag 10仍有较强中位特征自相关（0.834/0.728），B3_3为0.735；到lag 30时B3_3迅速降到0.035，而B3_1/B3_2仍为0.752/0.609。

固定步数窗口对不同寿命bearing并不代表相同的退化时间尺度。

### 5. 简单阶段切分不能直接解决

后40%阶段的中位`|feature–lifetime ρ|`在B3_1提高到0.438，但B3_3反而从早期0.562下降到后期0.211。因而当前证据不支持直接假设“只训练后期阶段就会统一方向”。

## 结论

主要瓶颈位于表示与任务定义，而不是LSTM容量：

1. 输入高度携带bearing身份；
2. 多数健康相关特征跨bearing方向不一致；
3. 线性RUL标签没有共享映射；
4. 固定10步窗口的相对尺度不一致。

继续增加LSTM层数、epoch或attention无法自动消除这些问题。当前也没有证据支持简单的固定phase切分。

## 下一步

优先复现能显式学习时间不变/实例不变表示的成熟方法，并把“降低bearing身份可识别性、保持LOBO健康排序”作为双重门槛。候选顺序：

1. TS2Vec式多尺度时间对比表示；
2. 加入bearing/domain对抗或MMD约束的表示对齐；
3. 在统一表示形成后再比较GRU、Attention或HMM解释层。

B3_4/B3_5继续保留，不用于选择下一种表示方法。
