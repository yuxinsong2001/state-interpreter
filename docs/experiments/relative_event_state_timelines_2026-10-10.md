# 相对状态统一时间线（2026-10-10）

## 本次完成内容
从已核对的状态接口归档生成九张三层时间线：上层特征偏离，中层因果趋势，下层候选事件状态。六张全程图覆盖B3_1–B3_3的RMS/峭度，三张局部图展示B3_1早期短事件、B3_2中期反复事件和末段退出再进入。

数据来源为`results/2026-10-09_relative_event_state_interface/states.csv`及`episode_terminations.csv`：10,810条状态、19个事件。只读取已保存CSV，没有重算状态、重训模型或读取B3_4/B3_5。输入SHA-256在绘图前后完全一致。

## 如何读图
- 横轴是0-based测量步编号，时长单位为已观察测量数。
- 上层有符号偏离单位为初始参考标准差；橙色虚线是固定2σ阈值。负值只是特征低于初始均值，不是负损伤。
- 中层是最近至多10个连续观察的斜率；负趋势表示近期特征下降，不等于设备恢复。校准期和不足2点的趋势保持空白。
- 下层Monitoring只是尚未确认活动事件；绿色区间为已确认活动事件。
- 橙色方块表示连续5次不超阈后的规则退出；三角表示记录结束时事件仍活动，持续时间带“+”表示右删失。
- 全程图连续纵轴采用symlog以保留正负和大幅值变化，局部图采用线性轴；不同轴尺度不应直接比较视觉斜率。
- 标签时长来自完整事件记录，即使局部窗口仅显示事件的一部分，也不缩短标签时长。

## 重点案例
**B3_1 RMS：**局部0–70步图显示第20步开始持续超阈，第24步确认；振动随后回落，趋势转负，第34步才在满足5次条件后退出。全程图显示第2339步重新进入末端事件。这使读者可区分瞬时值、近期方向和确认状态。

**B3_2 RMS：**1200–1750步图显示中期反复波动与多次规则退出。全程图显示较长的后段升高，并标出612步已结束事件与158步末端删失事件。2300–2370步图展示第2326步退出、第2338步重新进入；不能据退出推断物理健康恢复。

**B3_3：**全程图显示RMS/峭度在末端分别确认一个事件，仍为右删失。负趋势或曲线短暂下降也可能出现在活动区间；事件状态并非斜率符号的直接映射。

**RMS/峭度分歧：**B3_2峭度全程无确认事件，而RMS有12个。当前接口保留两路结果，不通过选取看起来更合理的图解决缺乏物理标签的问题。
