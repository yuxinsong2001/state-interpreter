# Technical Work Sample

[`State_Interpreter_Work_Sample_Yuxin_Song_EN.pdf`](State_Interpreter_Work_Sample_Yuxin_Song_EN.pdf) is a ten-slide English project overview prepared for technical job applications.

It includes:

- the vibration-to-state pipeline;
- the autoencoder and State Interpreter boundary;
- distance, HMM and GRU method comparisons;
- multi-seed LOBO validation;
- the Bearing2_5 joint blind evaluation;
- the Condition 3 domain-shift failure case;
- explicit limitations and transfer of validation methods to safety-related perception.

The PDF contains summarized public project evidence only. It does not contain raw XJTU-SY data, checkpoints or private source code. The editable PPTX is kept outside the public repository to avoid unnecessary binary history and duplicate artifacts.
