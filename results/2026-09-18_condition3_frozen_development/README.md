# Condition 3 frozen-development diagnostic

This directory contains the first preregistered development-only evaluation of the frozen Relative State Interpreter v2 on XJTU-SY Condition 3.

- `summary.csv`: one row per development bearing.
- `state_trajectories.csv`: time-ordered Level, Trend and Movement outputs.
- `condition3_development.png`: trajectory overview.
- `report.json`: machine-readable run report.
- `validation_report.json`: decision boundary and validity checks.

Only Bearing3_1–Bearing3_3 were read. Bearing3_4 and Bearing3_5 remain protected. The result does not support direct frozen cross-condition generalization, and no protected result was used for adaptation.
