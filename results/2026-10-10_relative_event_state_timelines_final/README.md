Nine plots from archived interface CSVs only; no model evaluation or protected data access.
Each plot aligns feature deviation, causal trend and candidate-event state.
Square markers: rule exit after five non-exceedances. Triangle markers and "+":
record-end censoring. Exit does not establish physical recovery.
